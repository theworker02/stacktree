# stacktree

Stack encode/decode helpers for tree payloads in pipelines.

**Site:** https://theworker02.github.io/stacktree/

## Install / run

```bash
git clone https://github.com/theworker02/stacktree.git
cd stacktree
node src/cli.js
node --test
```
